# 決めたことと理由

## 2026-10-23 出てくる会社名は架空のまま、本物らしさは別の所で出す
- **迷ったこと**: 架空の会社名だとゲームが物足りなくならないか。
- **決めたこと**: 実在の名前は使わない。そのうえで、ありそうな架空の会社が10問を通して何度も出てくるようにし、ゲームの中の「公式アプリで確かめる」行動を遊びにする。巧妙さは、文面や仕組み（受信者の名前入り、本物の SMS と同じスレッドに混ざる、似たドメイン名など）で出す。
- **理由**:
  - 詐欺は本物の会社名を名乗るので、名前は見抜く手がかりにならない。実在のドメインを差出人に使うメールが約 37.8 % ある（フィッシング対策協議会 月次報告 2026/09。research/scam-tactics/map.md の主張3）。ただしそのうち約 19.7 % は、受信拒否か迷惑メールへの隔離を指定したドメインのものなので、全部が受信箱に届くわけではない（同 月次報告）。
  - 公的機関が勧めるのは見た目で見抜くことより、「リンクを開かず、公式アプリやブックマークから確かめる」こと（同 主張4）。
  - 見た目の手がかりだけを教えると、本物まで避けるようになる副作用が報告されている（Sheng ら 2010。同 主張6）。
  - 実在の名前を使うと、商標の問題と、ゲームの画面が本物の詐欺の見本として悪用されるおそれがある（CLAUDE.md の決まり）。

## 2026-10-23 ドメインは予約済みの「.example」、電話番号は「●」で伏せる
- **決めたこと**: 画面に出すドメインは、例のために予約された `.example` だけにする（RFC 2606。だれも登録できない）。電話番号は一部を「●」で伏せる。
- **理由**: 架空の社名でも、`.com` や `.jp` のドメインを作ると、実在の会社のドメインと重なるおそれがある。重なると、実在の会社を「詐欺」として見せてしまう。電話番号も同じ。伏せ字は、フィッシング対策協議会の緊急情報や国民生活センターの注意喚起でも使われている書き方。
- **失うもの**: 「末尾が .com なら偽物」のような、実在のドメインの見分け方はそのまま練習できない。代わりに「公式のドメインと同じか」「最初の / の直前が本当の持ち主」という考え方を練習する。

## 2026-10-23 「確かめる」は1回のプレイで3回まで
- **理由**: 回数を無制限にすると、毎回押すだけで満点になり、見る目の練習にならない。現実には何回でも確かめてよいことは、結果の画面で伝える。

## 2026-10-23 題名は「それ、本物？」
- 画面に名前が要るので仮に置き、作者の確認を経てそのまま決めた。届いたメッセージを見て最初に思ってほしい問いをそのまま名前にした。

## 2026-10-23 作者の確認
- 「確かめる」3回まで、ドメインを `.example` だけにすることも、作者の確認を経てそのまま決めた。
