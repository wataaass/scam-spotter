# 調べもの: 詐欺の手口と見抜き方（2026-10-23）

ゲームの問題と解説を、公的機関の公表に沿って作るための下調べ。
調べ方は Claude Code のスキル [imozuru](https://github.com/MaryCache/imozuru) に沿った（原文を要約せずに集め、主張ごとに「どの原文の何行目か」を示す）。

| ファイル | 中身 |
|---|---|
| `report.html` | **最初に読む**。主張ごとに原文から切り出した文（抜き書き）を並べたページ。全 44 件を、原文の指定の行にそのまま在るか機械で照合済み |
| `map.md` | 問い・要る主張・用語・人・場（情報が集まる所）・原文の一覧・次の手がかり |
| `log.md` | 何を探して何が出たか、なぜそこで止めたか |
| `extracts.json` | `report.html` の元データ |

## 注意
- 原文そのもの（`sources/`）は、再配布しない決まりのためリポジトリに入れていない。各原文の URL は `map.md` の表にある。
- 抜き書きには実在の会社名（かたられたブランド名）が出てくるが、これは公的機関の原文の引用。**ゲームの問題では、決まりどおりすべて架空の名前にする**。
