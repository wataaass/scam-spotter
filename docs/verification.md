## 自動テスト（`npm test`）
105件。push のたびに GitHub Actions（`.github/workflows/ci.yml`）でも回る。

| ファイル | 確かめていること |
|---|---|
| `tests/questions.test.ts` | 10問あること・本物が3〜5問・SMS／メール／チャットと難しさ1〜3がそろうこと・解説の印がすべて画面の部品を指すこと・出典の URL の形・実在の社名が出ないこと・ドメインが `.example` だけ・電話番号が伏せてあること |
